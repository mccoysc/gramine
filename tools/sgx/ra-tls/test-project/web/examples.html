SGX DCAP Quote Verification - Usage Examples

⚠️ Security Notice: This JavaScript implementation is for testing and development. For production systems, always verify quotes on a trusted server with proper security controls.

Setup: Include Dependencies

First, include the required libraries in your HTML:

<!-- Dependencies -->
<script src="https://cdn.jsdelivr.net/npm/node-forge@1.3.1/dist/forge.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/cbor-web@9.0.0/dist/cbor.js"></script>
<script src="https://cdn.jsdelivr.net/npm/elliptic@6.5.4/dist/elliptic.min.js"></script>

<!-- SGX Quote Verifier -->
<script src="sgx-quote-verify.js"></script>

Example 1: Basic Verification

async function verifyQuote() {
    const certPem = `-----BEGIN CERTIFICATE-----
... your RA-TLS certificate ...
-----END CERTIFICATE-----`;

    try {
        const result = await SGXQuoteVerifier.verifyQuote(certPem, {
            pccsUrl: 'https://api.trustedservices.intel.com/sgx/certification/v4',
            allowDebugEnclave: false,
            allowOutdatedTcb: false
        });
        
        console.log('✓ Verification successful!');
        console.log('MRENCLAVE:', result.measurements.mrenclave);
        console.log('MRSIGNER:', result.measurements.mrsigner);
        console.log('TCB Status:', result.tcbStatus);
    } catch (error) {
        console.error('✗ Verification failed:', error.message);
    }
}

Example 2: Verification with Measurement Policy

Enforce that the enclave matches expected measurements:

async function verifyWithPolicy() {
    const result = await SGXQuoteVerifier.verifyQuote(certPem, {
        pccsUrl: 'https://api.trustedservices.intel.com/sgx/certification/v4',
        
        // Expected measurements (hex strings)
        expectedMrEnclave: '1234567890abcdef...',
        expectedMrSigner: 'fedcba0987654321...',
        
        // Expected product ID and security version
        expectedIsvProdId: 1,
        expectedIsvSvn: 1,
        
        // Security settings
        allowDebugEnclave: false,
        allowOutdatedTcb: false
    });
    
    // If we reach here, all measurements matched!
    console.log('✓ Enclave verified with policy');
}
Note: If any measurement doesn't match, an error will be thrown with a descriptive message.

Example 3: P-384 Quote Support

The library automatically detects and handles both P-256 and P-384 quotes:

const result = await SGXQuoteVerifier.verifyQuote(certPem, options);

if (result.attestationKeyType === 2) {
    console.log('P-256 quote (32-byte coordinates, SHA-256)');
} else if (result.attestationKeyType === 3) {
    console.log('P-384 quote (48-byte coordinates, SHA-384)');
}

Example 4: Custom PCCS Server

Use your own PCCS server instead of Intel's public service:

const result = await SGXQuoteVerifier.verifyQuote(certPem, {
    pccsUrl: 'https://your-pccs.example.com',
    apiKey: 'your-api-key-if-needed'
});

Example 5: Custom Root CAs

Provide your own trusted root certificates:

const customRootCA = `-----BEGIN CERTIFICATE-----
... your root CA ...
-----END CERTIFICATE-----`;

const result = await SGXQuoteVerifier.verifyQuote(certPem, {
    trustedRootCAs: [customRootCA]
});
Important: The built-in Intel Root CAs only include G1. For G3/G4, you must provide your own root CAs via this option.

Example 6: Error Handling

try {
    const result = await SGXQuoteVerifier.verifyQuote(certPem, options);
    console.log('Verified!');
} catch (error) {
    if (error.message.includes('MRENCLAVE mismatch')) {
        console.error('Wrong enclave code');
    } else if (error.message.includes('MRSIGNER mismatch')) {
        console.error('Wrong enclave signer');
    } else if (error.message.includes('Unsupported attestation key type')) {
        console.error('Invalid quote format');
    } else if (error.message.includes('TCB')) {
        console.error('TCB verification failed');
    } else {
        console.error('Verification failed:', error.message);
    }
}

API Reference

SGXQuoteVerifier.verifyQuote(input, options)

Parameters:

  • input (string): RA-TLS certificate in PEM format
  • options (object): Configuration options

Options:

  • pccsUrl (string): PCCS server URL (default: Intel public PCCS)
  • apiKey (string): API key for PCCS (optional)
  • expectedMrEnclave (string): Expected MRENCLAVE hex string (optional)
  • expectedMrSigner (string): Expected MRSIGNER hex string (optional)
  • expectedIsvProdId (number): Expected ISV_PROD_ID (optional)
  • expectedIsvSvn (number): Minimum ISV_SVN (optional)
  • allowDebugEnclave (boolean): Allow debug enclaves (default: false)
  • allowOutdatedTcb (boolean): Allow outdated TCB (default: false)
  • trustedRootCAs (array): Custom root CA PEMs (optional)
  • cacheRead (function): Cache read callback (optional)
  • cacheWrite (function): Cache write callback (optional)

Returns:

Promise that resolves to an object with:

  • verified (boolean): Always true if no error thrown
  • measurements (object): Enclave measurements
    • mrenclave (string): MRENCLAVE hex
    • mrsigner (string): MRSIGNER hex
    • isvProdId (number): ISV_PROD_ID
    • isvSvn (number): ISV_SVN
    • attributes (string): Attributes hex
    • reportData (string): Report data hex
  • tcbStatus (string): TCB status string
  • quoteVersion (number): Quote version (3 or 4)
  • attestationKeyType (number): 2 (P-256) or 3 (P-384)

Key Concepts

ECDSA Curves vs Hash Algorithms

It's important to distinguish between:

  • ECDSA Curves (for quote signatures): P-256 and P-384 only
  • Hash Algorithms (for pubkey-hash in claims): SHA-256, SHA-384, and SHA-512

SGX DCAP does NOT support P-512. The "512" refers to SHA-512 hash algorithm, not an ECDSA curve.

Attestation Key Types

  • Type 2 (P-256): 32-byte coordinates, 64-byte signatures, SHA-256 hashing
  • Type 3 (P-384): 48-byte coordinates, 96-byte signatures, SHA-384 hashing
